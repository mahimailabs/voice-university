## Classify Failures

For each mismatch, record whether a digit was substituted, deleted or inserted. Then inspect sequence length, repeated digits and the source audio. A label such as “bad audio” is not enough to suggest an intervention.

```python
import json
results = json.load(open('my-run/results.json'))
for row in results['predictions']:
    if row['reference'] != row['hypothesis']:
        print(row['files'], row['reference'], row['hypothesis'])
```

An empty hypothesis stays visible. A wrong string of the expected length is also a failure; length validation cannot recover which digit was spoken.

## Keep Comparisons

When you change decoding, save both old and new hypotheses for the same examples. Look for regressions as well as fixes. Reviewing only newly correct cases would bias the narrative.
