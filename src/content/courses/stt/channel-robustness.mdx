A robustness comparison should change the channel condition while keeping the underlying examples fixed. The lab's probe script adds deterministic Gaussian noise to the same evaluation sequences and reruns the retained checkpoint.

## Run Probes

```sh
python probes.py --data fsdd --run my-run
```

The SNR calculation uses full-clip RMS, including inserted silence. Noise is regenerated from a fixed seed for each example. The script does not clip or renormalise the mixture after adding noise. Those details matter when another implementation tries to reproduce the results.

## Interpret Limits

These are synthetic noise probes on a development set. They are not recordings from a carrier network, a workshop or a moving vehicle. White noise is a controlled perturbation; it does not reproduce competing speakers or reverberation.

A severe degradation tells us this baseline is fragile under this transform. It does not identify the best remedy. Augmentation, frontend processing and different training data should be separate experiments with the same evaluation boundary.

## Paired Review

Retain clean and noisy hypotheses for each sequence when developing further probes. Identify cases that changed from correct to incorrect and the reverse. Aggregate percentages can hide both kinds of movement.
