The retained checkpoint is epoch 23. The run continued to epoch 60, but the selection rule kept the earliest checkpoint with the lowest observed validation digit error rate. Continuing to train did not automatically earn a replacement.

## Selection Rule

```python
if validation_digit_error_rate < best:
    best = validation_digit_error_rate
    torch.save(model.state_dict(), 'best.pt')
```

The strict comparison retains the earlier checkpoint on a tie. A different rule is valid if declared before inspecting the results: for example, a minimum exact-match requirement followed by lower latency. Do not quietly switch metrics after seeing which one makes a run look better.

## Save Provenance

Retain model weights, vocabulary, feature recipe, dataset revision, split manifest, package versions and checkpoint checksum. A weight file without its input contract is not a reproducible recognizer.

```python
import hashlib
with open('my-run/best.pt', 'rb') as f:
    print(hashlib.sha256(f.read()).hexdigest())
```

Compare this with the corresponding field in `results.json`, not with another machine's training output. Seeds help reproduce a run but do not promise identical results across every platform.
