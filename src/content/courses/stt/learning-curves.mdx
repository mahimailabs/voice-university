## Blank Outputs

Early CTC training can put enough probability on blank that the greedy path collapses to an empty string. The loss can still improve as probability mass changes among paths. Keep empty outputs in both error calculations and qualitative review.

To inspect the relationship yourself:

```python
import json
history = json.load(open('my-run/history.json'))
for row in history:
    print(row['epoch'], row['train_loss'], row['validation_der'])
```

## Generalisation Gap

By the final epoch, training loss was about 0.0019 while validation digit error rate was 36.25%. That gap is a warning about this small training setup and its held-out speaker, not proof of one single cause. Data diversity, augmentation and architecture are hypotheses to test separately.

A smooth loss curve is especially unhelpful if the target policy or split is wrong. Review [Transcript Policy](/learn/100x/stt/transcript-policy) and [Speaker Splits](/learn/100x/stt/speaker-splits) before interpreting an apparent improvement.
