The harness is the boundary around a comparison. It should let another reader reconstruct which examples were scored, how outputs became strings and which model produced them. A single percentage is not enough.

## Report Contract

| Evidence | Saved location |
| --- | --- |
| Dataset revision and runtime | `results.json` |
| Source clips and split | `manifest.json` |
| Epoch selection history | `history.json` |
| Raw reference and hypothesis | `results.json` predictions |
| Checkpoint identity | SHA-256 in `results.json` |
| Channel and prefix probes | `probes.json` |

The [lab download](/labs/stt/stt-lab.zip) includes the recorded run and executable source. Use a new output directory for a new experiment so earlier evidence is not silently replaced.

## Comparison Protocol

Freeze the evaluation examples and scoring policy. Change one meaningful factor, such as decoder width or training data. Save the new configuration, run it against the same examples and inspect paired differences.

The training script writes validation summaries each epoch and selects the checkpoint before evaluating the development holdout. The earlier pilot disclosure still applies: these numbers are not an untouched final test.

## Release Questions

A production evaluation needs additional coverage: real channels, languages, speakers, silence, overlapping speech, longer identifiers and task outcomes. This lab deliberately provides none of those claims.
